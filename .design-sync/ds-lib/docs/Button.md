# Button

The primary interactive control. Use `variant="primary"` (gold gradient + glow) for the single main call to action per view; `secondary` for neutral/cancel actions; `ghost` for low-emphasis inline actions; `danger` (rose) for destructive ones. Add `block` for full-width form buttons, `iconOnly` for a square 38×38 icon button.

```jsx
<Button variant="primary">Add account</Button>
<Button variant="ghost">Edit budget</Button>
<Button variant="danger">Remove debt</Button>
```
